TokSave Developer API

Satu endpoint buat ambil data video TikTok, Instagram, dan YouTube secara terprogram. Gratis, tanpa perlu kartu kredit.

Penting sebelum mulai: untuk Instagram & YouTube, kamu wajib bawa API key FastSaverAPI milikmu sendiri di setiap request (gratis, daftar sendiri di sana). TokSave tidak menyediakan atau meneruskan key FastSaverAPI miliknya sendiri ke siapa pun — cuma jadi jembatan yang menyatukan tiga platform dalam satu endpoint. TikTok tidak butuh key sama sekali.

1. Daftar, dapat API key gratis

2. Contoh Pemakaian

TikTok (tidak butuh key FastSaverAPI):

curl "https://toksave-download.vercel.app/api/v1/media?url=https://vt.tiktok.com/xxxxx/" \
  -H "X-TokSave-Key: tsk_xxxxxxxxxxxxxxxx"

Instagram (wajib bawa key FastSaverAPI sendiri):

curl "https://toksave-download.vercel.app/api/v1/media?url=https://www.instagram.com/reel/xxxxx/" \
  -H "X-TokSave-Key: tsk_xxxxxxxxxxxxxxxx" \
  -H "X-FastSaver-Key: fs_sk_key_milikmu_sendiri"

YouTube (wajib bawa key FastSaverAPI sendiri, format opsional):

curl "https://toksave-download.vercel.app/api/v1/media?url=https://youtu.be/xxxxx&format=720p" \
  -H "X-TokSave-Key: tsk_xxxxxxxxxxxxxxxx" \
  -H "X-FastSaver-Key: fs_sk_key_milikmu_sendiri"

JavaScript (fetch):

const res = await fetch(
  'https://toksave-download.vercel.app/api/v1/media?url=' + encodeURIComponent(videoUrl),
  {
    headers: {
      'X-TokSave-Key': 'tsk_xxxxxxxxxxxxxxxx',
      'X-FastSaver-Key': 'fs_sk_key_milikmu_sendiri' // kosongkan kalau TikTok
    }
  }
);
const data = await res.json();
console.log(data.videoUrl);

3. Format Respons

Contoh respons sukses untuk video biasa:

{
  "success": true,
  "platform": "tiktok",
  "type": "video",
  "videoUrl": "https://...",
  "audioUrl": "https://...",
  "thumbnail": "https://...",
  "title": "Judul video",
  "author": "username",
  "meta": { "requestsToday": 3, "dailyLimit": 100 }
}

Untuk carousel/album (Instagram/TikTok slideshow), field images berisi array URL, dan type bernilai "album".

4. Batas Pemakaian

ItemBatas
Request harian per API key100 / hari

Kalau butuh limit lebih tinggi, hubungi kami lewat halaman utama.

StatusArti
